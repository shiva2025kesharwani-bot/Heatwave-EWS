# Extreme Heatwave Early Warning & Human Thermal Stress Index

Full-stack platform for detecting, forecasting, and warning about extreme heatwaves using human thermal stress indices (UTCI, WBGT, HI).

## Stack
- **Data/ML:** Python, Xarray, scikit-learn, PyTorch, Airflow/Prefect
- **Backend:** FastAPI + PostgreSQL/PostGIS + Redis + Celery
- **Frontend:** React + Vite + Tailwind + Leaflet
- **Mobile:** React Native (Expo)
- **Streaming:** Kafka + MQTT
- **Ops:** Docker, Kubernetes, Terraform, GitHub Actions, Prometheus/Grafana
